# SM Energy Pricer — Heston · Lewis · Bates

A production-style quantitative pricing application for **MScFE 622 Group Work Project 1** (WorldQuant University).

It calibrates Heston (1993) and Bates (1996) stochastic-volatility models to SM Energy option quotes using the
**Lewis (2001)** and **Carr–Madan (1999)** Fourier transforms, prices an **Asian call** and a **European put** by
Monte Carlo (Andersen 2008 QE scheme with jumps), and calibrates **CIR (1985)** to the Euribor curve for one-year
rate scenarios.
